Amazon RDS

Criação de um banco de dados relacional gerenciado e integração com uma aplicação web executada no Amazon EC2.

O PROJETO

Um banco de dados gerenciado na nuvem

Neste laboratório, configurei uma instância Amazon RDS para MySQL em uma implantação Multi-AZ e conectei o banco a uma aplicação web hospedada em uma instância EC2. A aplicação Address Book foi utilizada para testar a inclusão, a edição e a remoção de contatos.

☁ Serviço Amazon RDS
▤ Mecanismo MySQL
◈ Implantação Multi-AZ
⌘ Aplicação Address Book
ARQUITETURA

Como os componentes se conectam

A aplicação web no EC2 acessa o banco RDS pela rede privada da Lab VPC. O Security Group do banco permite conexões MySQL originadas do Web Security Group.

🌐 Aplicação web Amazon EC2 Web Security Group
→
🛡 Controle de acesso DB Security Group MySQL · TCP 3306
→
▤ Banco de dados Amazon RDS MySQL · Multi-AZ

CONHECIMENTOS PRATICADOS

O que foi colocado em prática

01

Amazon RDS e MySQL

Criação e configuração de uma instância de banco de dados relacional gerenciado.

02

Alta disponibilidade com Multi-AZ

Configuração de instância principal e instância em espera em Zonas de Disponibilidade diferentes.

03

Rede e segurança

Configuração de DB Subnet Group com subnets privadas e controle de conexões por Security Group.

04

Conectividade com a aplicação

Uso do endpoint do RDS para conectar a aplicação web ao banco pela porta TCP 3306.

APRENDIZADO

O que aprendi

✓

Integração entre aplicação e banco de dados

A prática permitiu compreender como um banco de dados gerenciado pode ser implantado em subnets privadas, protegido por regras de rede e acessado por uma aplicação hospedada no EC2. Também pratiquei a configuração de uma implantação Multi-AZ e a utilização do endpoint para estabelecer a conexão com o RDS.
